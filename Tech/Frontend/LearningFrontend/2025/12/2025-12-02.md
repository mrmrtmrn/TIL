## 学んだこと・気づき

### 関数の基本
- 関数の宣言方法は `function 関数名(引数1, 引数2, ...) { return 戻り値; }` の形式
- 仮引数より少ない引数で呼び出すと、不足分は `undefined` になる
- 仮引数より多い引数は無視される

### デフォルト引数と可変長引数
- ES2015からデフォルト引数が使える（例: `function fn(x = "default value")`）
- Rest parameters（残余引数）: `...args` で任意の個数の引数を配列として扱える
- Rest parametersは必ず最後に配置する必要がある

### 関数式とアロー関数
- 関数は値として扱える（ファーストクラスファンクション）
- 関数式: 関数を変数に代入する（無名関数・匿名関数）
- 名前付き関数式: 関数内で再帰呼び出しに使える
- アロー関数: `(name) => {}` の形式で、より簡潔に記述可能
  - 引数が1つなら括弧省略可能
  - 処理が1行でreturnのみなら中括弧とreturnも省略可能
  - コールバック関数を渡す場合に便利

### 関数の上書きと防止策
- 関数名が被った場合は後勝ち（仮引数の数は関係ない）
- `const` で関数式を定義すれば、再宣言がエラーになり意図しない上書きを防げる

### 高階関数とコールバック関数
- コールバック関数: 引数として渡される関数
- 高階関数: コールバック関数を引数として受け取る関数

### メソッド
- オブジェクトのプロパティとして定義された関数
- ES2015以降の省略記法: `shortGreet(name) { ... }`

### 分割代入
- 関数の引数に分割代入を使用可能
- オブジェクトの場合: プロパティ名に対応して代入（例: `function fn({ x, y })`）
- 配列の場合: 順番に値が入る（例: `function fn([a, b])`）

### その他
- `arguments` 変数: 関数に渡された全引数を格納（Array-likeだが厳密には配列ではない）
- 極力 `arguments` より Rest parameters を使うべき
- アロー関数と通常の関数では `this` の扱いが異なる（後の章で解説予定）
