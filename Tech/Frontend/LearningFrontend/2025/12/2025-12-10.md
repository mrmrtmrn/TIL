## 学んだこと・気づき

### オブジェクトの基本

- オブジェクトはプロパティ（キーとバリューのセット）の集合
- `Object`はあらゆる環境で利用できる組み込み（ビルトイン）オブジェクト
- オブジェクトリテラル `{}` で作成可能
- キーが変数名のルールに従わない場合は文字列として記述する必要がある（例: `"key-3"`）

### プロパティへのアクセス

- ドット記法: `obj.key1`
- ブラケット記法: `obj["key1"]`（変数や特殊文字を含むキーでも使える）
- 存在しないプロパティにアクセスすると`undefined`が返る

### プロパティの追加・削除・確認

```javascript
// 追加
obj.newKey = "newValue";
obj["another-key"] = "another-value";

// 削除
delete obj.newKey;

// 存在確認
"key" in obj; // in演算子
Object.hasOwn(obj, "key"); // [ES2022]
obj.hasOwnProperty("key"); // [ES2022以降]
```

### ES2015以降の便利な機能

#### プロパティの省略記法

```javascript
const name = "Alice";
const obj = { name }; // { name: "Alice" } と同じ
```

#### 分割代入

```javascript
const languages = { ja: "日本語", en: "英語" };
const { ja, en } = languages; // プロパティを取り出す
```

### Optional Chaining演算子 [ES2020]

ネストしたプロパティに安全にアクセスできる：

```javascript
// 従来の書き方（冗長）
if (obj.propertySet !== undefined && obj.propertySet.property !== undefined) {
  console.log(obj.propertySet.property);
}

// Optional Chainingを使った簡潔な書き方
console.log(obj.propertySet?.property ?? "プロパティが存在しない");

// ブラケット記法でも使える
console.log(obj["propertySet"]?.["property"] ?? "プロパティが存在しない");
```

プロパティがあればその値を返し、なければ`undefined`を返す。Nullish coalescing（`??`）と組み合わせてデフォルト値を設定できる。

### toStringメソッドのカスタマイズ

```javascript
const customObj = {
  key: "value",
  toString() {
    return `customObj: { key: ${this.key} }`;
  }
};
console.log(String(customObj)); // "customObj: { key: value }"
```

`String`コンストラクタは引数に渡されたオブジェクトの`toString`メソッドを呼び出す。

### Objectクラスの主な静的メソッド

```javascript
const obj = { a: 1, b: 2, c: 3 };

Object.keys(obj); // ["a", "b", "c"] - キーの配列
Object.values(obj); // [1, 2, 3] - 値の配列
Object.entries(obj); // [["a", 1], ["b", 2], ["c", 3]] - キーと値のペアの配列
```

すべて列挙可能なプロパティのみを対象とする。

### オブジェクトのマージ

#### Object.assign [ES2015]

```javascript
const obj1 = { a: 1 };
const obj2 = { b: 2 };
const mergedObj = Object.assign({}, obj1, obj2); // { a: 1, b: 2 }
```

**注意**: 第1引数のオブジェクトが変更されるため、空のオブジェクトを渡すのが安全。

#### スプレッド構文 [ES2018]

```javascript
const mergedObj = { ...obj1, ...obj2 }; // { a: 1, b: 2 }
```

オブジェクトリテラルの中でしか使えないため、必ず新しいオブジェクトを返す。より安全で推奨される方法。

### オブジェクトのコピー

```javascript
// 浅いコピー（objの直下のプロパティのみコピー）
Object.assign({}, obj);
// または
{ ...obj };
```

深いコピーをする場合には再帰的に浅いコピーを実行する必要がある。
