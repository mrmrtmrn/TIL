# 🧠 TIL (Today I Learned) Repository

このリポジトリは、日々の学習や読書、技術的な発見を記録するためのパーソナルなナレッジベースです。
学んだことを忘れないうちにアウトプットし、整理することを目的としています。

---

## 📁 リポジトリの構成 (Structure)

コンテンツは大きく以下の3つのカテゴリに分けて管理されています。

| フォルダ名 | 概要 | 目的 |
| :--- | :--- | :--- |
| `Tech/` | IT技術に関する学び。 | 技術的な知識の定着とスキルアップ。 |
| `Books/` | 読んだ本の内容や要点、感想などの記録。 | 読書の振り返り、知識の整理。 |
| `Diary/` | 日々の活動、簡単な振り返り、個人的な雑記。 | 日々の記録、モチベーション管理。 |

---

## 🔗 主要カテゴリへのリンク

各フォルダの最新の内容へは、以下のリンクからアクセスできます。

* [📚 Books/ - 読書記録](/Books)
* [📅 Diary/ - 日記・日々の振り返り](/Diary)
