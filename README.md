# 🧠 TIL (Today I Learned) Repository

このリポジトリは、日々の学習や読書、技術的な発見を記録するためのパーソナルなナレッジベースです。
学んだことを忘れないうちにアウトプットし、整理することを目的としています。

---

## 📁 リポジトリの構成 (Structure)

コンテンツは以下のカテゴリに分けて管理されています。

| フォルダ名 | 概要 | 目的 |
| :--- | :--- | :--- |
| `docs/Tech/` | IT技術に関する学び。 | 技術的な知識の定着とスキルアップ。 |
| `docs/Books/` | 読んだ本の内容や要点、感想などの記録。 | 読書の振り返り、知識の整理。 |
