### 1. JavaScript Primer - 文と式、条件分岐、ループと反復処理

learning-frontend リポジトリの学習を進め、JavaScript Primer の「文と式」「条件分岐」「ループと反復処理」の章を学習しました。

**学んだ主な内容:**

#### 文と式の違い
- **式**: 値を生成し、変数に代入できるもの（リテラル、変数、関数呼び出しなど）
- **文**: if文やfor文などの処理単位。セミコロンで区切る
- **式文**: 文になった式のこと
- if文は式ではないため変数に代入できない

```javascript
// 関数式（式なので変数に代入可能）
const fn = function() {
  return 1;
};

// if文は式ではないので変数に代入できない
// const x = if (true) { ... } // エラー
```

#### ブロック文とスコープ
- `{}` で文をまとめる
- ブロックごとにスコープが分かれる
- ブロック文で終わる場合はセミコロン不要

```javascript
{
  const x = 1;
}
// xはブロック外から参照できない

{
  const x = 2; // 別スコープなので再定義OK
}
```

#### 関数宣言と関数式のセミコロンの違い
```javascript
function learn() {
} // 文なのでセミコロン不要

const fn = function() {
}; // 式なのでセミコロン必要
```

#### 条件分岐とfalsyな値
- if文の条件式にboolean以外の値を指定すると暗黙的な型変換が行われる
- falsyな値: `false`, `undefined`, `null`, `0`, `0n`, `""`, `NaN`
- switch文は厳密等価演算子（`===`）で比較される

#### ループと反復処理の使い分け
- **while文**: 条件式がtrueの間繰り返し
- **do-while文**: 最低1回は実行される
- **for文**: 初期化式、条件式、増分式を指定
- **forEach**: 配列の各要素に対して繰り返し実行
- **for...in文**: オブジェクトの列挙可能なプロパティを反復（`Object.keys()` + `forEach` のほうが安全）
- **for...of文**: イテラブルオブジェクトを反復（配列の値を取り出せる）

```javascript
const array = [10, 20, 30];

// for...of は配列の値を取り出す
for (const value of array) {
  console.log(value); // 10, 20, 30
}

// for...in は配列のインデックスが出力される
for (const value in array) {
  console.log(value); // 0, 1, 2
}
```
