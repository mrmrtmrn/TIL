### JavaScript Primer でオブジェクトの基礎を学習

learning-frontend リポジトリで JavaScript Primer を使って JavaScript の基礎を学習し直し中。今回は5日目と6日目の学習内容をまとめた。

#### オブジェクトの基本操作

- オブジェクトはプロパティ（キーとバリューのセット）の集合
- オブジェクトリテラル `{}` で作成
- ドット記法とブラケット記法でプロパティにアクセス可能
- 存在しないプロパティは `undefined` を返す

```javascript
const obj = {
  key1: "value1",
  "key-2": "value2" // 変数名のルールに従わない場合は文字列で記述
};

obj.key1; // ドット記法
obj["key-2"]; // ブラケット記法（特殊文字を含むキーに必要）
```

#### プロパティの追加・削除・確認

```javascript
// 追加
obj.newKey = "newValue";

// 削除
delete obj.newKey;

// 存在確認
"key" in obj; // in演算子
Object.hasOwn(obj, "key"); // [ES2022]
```

#### ES2015以降の便利な機能

**省略記法**:
```javascript
const name = "Alice";
const obj = { name }; // { name: "Alice" }
```

**分割代入**:
```javascript
const { ja, en } = languages; // プロパティを直接変数に取り出す
```

#### Optional Chaining演算子 [ES2020]

ネストしたプロパティに安全にアクセスできる画期的な機能：

```javascript
// 従来の冗長な書き方
if (obj.propertySet !== undefined && obj.propertySet.property !== undefined) {
  console.log(obj.propertySet.property);
}

// Optional Chainingで簡潔に
console.log(obj.propertySet?.property ?? "プロパティが存在しない");
```

プロパティが存在すればその値を返し、存在しなければ `undefined` を返す。Nullish coalescing（`??`）と組み合わせてデフォルト値を設定できる。

#### Object静的メソッド

```javascript
const obj = { a: 1, b: 2, c: 3 };

Object.keys(obj); // ["a", "b", "c"]
Object.values(obj); // [1, 2, 3]
Object.entries(obj); // [["a", 1], ["b", 2], ["c", 3]]
```

#### オブジェクトのマージ

**Object.assign [ES2015]**:
```javascript
const mergedObj = Object.assign({}, obj1, obj2);
```
注意: 第1引数のオブジェクトが変更されるため、空のオブジェクトを渡すのが安全。

**スプレッド構文 [ES2018]（推奨）**:
```javascript
const mergedObj = { ...obj1, ...obj2 };
```
オブジェクトリテラルの中でしか使えないため、必ず新しいオブジェクトを返す。より安全。

#### オブジェクトのコピー

```javascript
// 浅いコピー
Object.assign({}, obj);
// または
{ ...obj };
```

浅いコピーは直下のプロパティのみをコピー。深いコピーが必要な場合は再帰的に処理する。
