# 2025-12-01 学習記録

## 今日学んだこと

### 1. Learning Frontend の進捗記録システムの活用

**概要**
`/daily-all` コマンドを使って、複数リポジトリの学習記録を一括生成する仕組みを実際に体験した。

**詳細**
- Learning Frontend リポジトリの進捗を自動で取得・記録
- `.last-commit.json` でコミット追跡を管理
- `logs/day02.md` から学習内容を自動収集
- TIL リポジトリに `Tech/Frontend/LearningFrontend/2025/12/2025-12-01.md` として記録

**学んだこと**
- GitHub API を使ったコミット差分の取得方法
- WebFetch を使った外部リソースの取得
- 複数リポジトリ間での学習記録の連携

### 2. JavaScript の基礎（Learning Frontend より）
