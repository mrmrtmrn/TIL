# 2025-11-19の学習記録

## 今日学んだこと

### 1. Claude Code のカスタムスラッシュコマンド

Claude Code にはスラッシュコマンド機能があり、カスタムコマンドを作成できることを学びました。`.claude/commands/` ディレクトリ配下に Markdown ファイルを配置することで、独自のコマンドを定義できます。

**作成したカスタムコマンド:**
```markdown
---
description: "本日のmainブランチとの差分から学習記録を作成"
---

以下の手順で本日の学習記録を作成してください：

1. 現在のブランチ名を確認し、ブランチ名から日付を抽出
   - ブランチ名は `YYYY-MM-DD` 形式（例: `2025-11-19`）
   - **重要**: サマリファイルの日付は、コマンド実行日ではなく、必ずブランチ名の日付を使用すること
2. mainブランチとの差分を確認...
```

このコマンドにより `/daily-summary` を実行するだけで、自動的に学習記録を作成できるようになりました。

**参考:** [カスタムスラッシュコマンド - Claude Code Docs](https://code.claude.com/docs/ja/slash-commands#%E3%82%AB%E3%82%B9%E3%82%BF%E3%83%A0%E3%82%B9%E3%83%A9%E3%83%83%E3%82%B7%E3%83%A5%E3%82%B3%E3%83%9E%E3%83%B3%E3%83%89)

### 2. デイリーサマリテンプレートの作成

日々の学習記録を効率的に作成するため、`.templates/daily-diary.md` というテンプレートファイルを作成しました。このテンプレートを使うことで、一貫性のある記録を残せるようになりました。

**テンプレートの構造:**
- 日付
- 今日学んだこと（複数トピック対応）
- コード例やコマンド例
- 参考リンク
- まとめセクション

### 3. CONTRIBUTING.md の改善

Git ワークフローのドキュメントを改善しました。具体的には、日付を手動で入力する代わりに、シェルコマンドで自動的に本日の日付を使用するように修正しました。

**修正前:**
```bash
git switch -c 2025-11-19
```

**修正後:**
```bash
git switch -c $(date +%Y-%m-%d)
```

これにより、ドキュメントのメンテナンス性が向上し、コピー&ペーストでそのまま使えるようになりました。
