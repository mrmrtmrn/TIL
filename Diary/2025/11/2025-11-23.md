# 2025-11-23の学習記録

## 今日学んだこと

### 1. MyApp/ カテゴリの新設と進捗管理の仕組み

TILリポジトリで個人開発プロジェクトの進捗を記録するための新しいカテゴリ `MyApp/` を作成した。

**目的:**
- 別リポジトリで開発中のプロジェクトの進捗をTILとして記録
- プロジェクトごとにサブディレクトリを作成（例: `MyApp/MyBlog/`）
- 日々の作業内容、学んだこと、次にやることを管理

**作成したファイル:**
- `MyApp/MyBlog/進捗テンプレート.md` - 進捗記録用のテンプレート
- `MyApp/MyBlog/2025-11-23.md` - 初回の進捗記録

**更新ルール:**
1. my-blog リポジトリの main ブランチの変更のみを記録
2. コミットハッシュで「どこまで記録したか」を管理
3. 前回のハッシュ以降〜最新までを記録範囲に
4. ファイル名は TIL のブランチ名（日付）を使用

### 2. `/myblog-progress` カスタムコマンドの作成

MyBlog プロジェクトの進捗記録を自動生成するカスタムコマンドを実装した。

**動作の流れ:**
1. 前回の進捗ファイルから最新のコミットハッシュを取得
2. my-blog リポジトリの main ブランチで新しいコミットをチェック
3. 変更がなければ「新しい変更はありません」と表示して終了
4. 変更があれば `MyApp/MyBlog/YYYY-MM-DD.md` を自動生成
   - コミット履歴を「今日やったこと」に自動入力
   - 対象コミット範囲を自動設定

**使い方:**
```
/myblog-progress
```

**ポイント:**
- `gh` CLI を使ってプライベートリポジトリのコミット履歴を取得
- テンプレートをベースに進捗ファイルを自動生成
- 手動で記入する部分（概要、学んだこと、次にやること）は空欄のまま

### 3. GitHub CLI を使った issue 管理

進捗記録の「次にやること」を my-blog リポジトリの issue として登録した。

**コマンド例:**
```bash
gh issue create --repo mrmrtmrn/my-blog --title "タイトル" --body "内容"
```

**作成した issue:**
- #1: mainブランチの保護設定
- #2: Dockerの設定理解
- #3: Railsで使っているgemの理解
- #4: React側の構成理解

**ポイント:**
- `gh` CLI を使えば、別リポジトリの issue も簡単に作成できる
- TIL で進捗を記録し、実際のタスク管理は開発リポジトリの issue で行う連携が可能

## まとめ

本日は、TILリポジトリと個人開発プロジェクト（my-blog）を連携させる仕組みを構築した。

`MyApp/` カテゴリの新設により、別リポジトリで開発中のプロジェクトの進捗をTILとして記録できるようになった。また、`/myblog-progress` コマンドにより、進捗記録の作成が自動化された。

さらに、`gh` CLI を使って進捗記録の「次にやること」を開発リポジトリの issue として登録することで、TIL での振り返りと実際のタスク管理を連携させることができた。

次のステップとして、my-blog の issue を消化しながら、Docker や Rails、React の理解を深めていく。
