# 2025-11-29の学習記録

## 今日学んだこと

### 1. Claude Code の CLAUDE.md でファイルインポート機能

CLAUDE.md ファイル内で `@` 構文を使うことで、他のファイルを読み込ませることができる機能を学んだ。これにより、CLAUDE.md 本体をシンプルに保ちながら、必要な情報を別ファイルに分割して管理できる。

**構文例:**
```markdown
詳細は @README.md を参照してください
プロジェクトの設定は @.github/CONTRIBUTING.md を確認してください
```

**特徴:**
- 相対パス・絶対パス（`@~/path/to/file.md`）の両方に対応
- 再帰的インポートが可能（最大5階層まで）
- コードブロック内では展開されない

**確認方法:**
セッション中に `/memory` コマンドを実行すると、現在読み込まれているメモリファイルの一覧を確認できる。

**参考:** https://code.claude.com/docs/en/memory.md

### 2. カスタムコマンド `/myblog-progress` のメンテナンス

MyBlog プロジェクトの進捗記録を自動生成するカスタムコマンドを修正した。進捗テンプレートから「次にやること」セクションを削除したのに、カスタムコマンドの定義に残っていたため、不要なセクションが生成されていた。

**修正箇所:**
- `.claude/commands/myblog-progress.md` から「次にやること」への言及を3箇所削除
  - 手動で埋める内容のリスト
  - 保持する内容のリスト
  - 結果報告メッセージ

**学び:**
- カスタムコマンドはテンプレートファイルとの整合性を保つ必要がある
- 仕様変更時は、関連するドキュメントやコマンド定義も合わせて更新する

### 3. MyBlog プロジェクトの進捗管理

`/myblog-progress` コマンドを使って、my-blog リポジトリの進捗を TIL リポジトリに記録した。GitHub API と GitHub Project を活用して、コミット履歴と Issue の状態を自動で取得・記録する仕組みを運用。

**記録内容:**
- **対象コミット範囲**: `26e4635` → `ddf1e61` (7件のコミット)
- **完了した Issue**: 13件（バックエンド・フロントエンド両面）
  - Posts API の CRUD エンドポイント実装
  - RSpec によるリクエストスペック追加
  - React のページコンポーネント作成
  - TypeScript 型定義と API クライアント作成

**使用したコマンド:**
```bash
# コミット履歴の取得
gh api repos/mrmrtmrn/my-blog/commits --jq '.[] | "\(.sha) \(.commit.message | split("\n")[0])"'

# GitHub Project から Issue 情報を取得
gh project item-list 9 --owner mrmrtmrn --format json --limit 100
```

**重複防止の仕組み:**
`.done-issues.json` ファイルで記録済みの Done issue を管理し、同じ issue が複数回記録されないようにしている。

**参考:** https://github.com/mrmrtmrn/my-blog
