# 2025-11-24の学習記録

## 今日学んだこと

### 1. Claude Code カスタムコマンドで GitHub Project の issue を追跡する

`/myblog-progress` コマンドを拡張して、GitHub Project から issue の状態（Done/In Progress）を取得し、進捗ファイルに自動記録する機能を実装した。

**GitHub Project から issue を取得するコマンド:**
```bash
gh project item-list 9 --owner mrmrtmrn --format json --limit 100
```

**ポイント:**
- Done issue は `.done-issues.json` で記録済みを管理し、重複を防ぐ
- In Progress の issue は毎回表示（作業中の可視化）
- issue はリンク付きで出力：`[#1 タイトル](URL)`

### 2. カスタムコマンドの追記モード実装

同じ日に複数回コマンドを実行しても、手動入力した内容（学んだこと・気づき等）が消えないよう、追記モードを実装した。

**設計方針:**
- 既存ファイルがある場合は、コミットとissue部分のみ更新
- 概要は全体の内容から再生成
- 手動入力セクションは保持

### 3. コミットとissueの両方から概要を自動生成

進捗ファイルの「概要」セクションを、コミットメッセージと完了issueの情報から自動生成するようにした。

**生成例:**
- コミットのみ: 「Rails APIとReactフロントエンドの初期セットアップを実施」
- issueのみ: 「Docker設定理解、mainブランチ保護設定の2つのissueを完了」
- 両方: 「Post モデルの実装を行い、モデル作成のissueを完了」

## まとめ

Claude Code のカスタムコマンド（`/myblog-progress`）を大幅に強化した。GitHub Project との連携により、issue の進捗も自動で進捗ファイルに記録できるようになった。追記モードにより、1日に複数回実行しても安全に更新できる。また、APIは毎回必ず実行して最新情報を取得する必要があることを学んだ（キャッシュを使わない）。
