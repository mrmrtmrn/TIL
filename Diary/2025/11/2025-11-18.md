# 2025-11-18の学習記録

## 今日学んだこと

### 1. GitHub CLIを使ったプルリクエストの作成

GitHub CLIの`gh pr create`コマンドを使って、コマンドラインからプルリクエストを作成する方法を学んだ。

**基本コマンド:**
```shell
gh pr create --assignee "@me" --base main --title "TIL : 2025-11-18" --body ""
```

- `--assignee "@me"`: 自分をアサイニーに設定
- `--base main`: マージ先のブランチを指定
- `--title`: PRのタイトルを指定
- `--body`: PRの本文を指定

これにより、ブラウザを開かずにコマンドラインからスムーズにプルリクエストを作成できるようになった。

**参考:** [pull request の作成 - GitHub ドキュメント](https://docs.github.com/ja/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request?tool=cli)

### 2. TILリポジトリのGit運用ルールの整備

個人のTILリポジトリでも、一貫性と品質を保つために、以下のGit運用ルールを文書化した（CONTRIBUTING.md）：

- **mainブランチへの直接コミットを禁止**
- **ブランチ命名規則**: `YYYY-MM-DD`形式（例: `2025-11-18`）
- **プルリクエストベースのワークフロー**

日々の更新手順：
1. mainブランチを最新化
2. 日付ベースのブランチを作成
3. 変更をコミット・プッシュ
4. プルリクエストを作成してマージ
5. ローカルブランチのクリーンアップ

### 3. Claude Code用のガイドライン作成

将来のClaude Codeインスタンスが効率的に作業できるよう、CLAUDE.mdファイルを作成した。

含めた内容：
- リポジトリの概要と構成

- よく使うコマンド（日次ブランチ作成、コミット、PR作成）
- コンテンツガイドライン

これにより、Claude Codeが初めてこのリポジトリで作業する際も、適切なワークフローに従って作業できるようになった。
