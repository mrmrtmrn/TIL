# AI Session Notes - 2026-03-14

## Claude Code のスキル（Skills）システム

### 学んだこと

- Claude Code には「スキル（Skills）」というプラグインのような仕組みがあり、特定のタスクに特化した知識やワークフローを提供する
- スキルはインストール不要で、利用可能なスキル一覧に表示されていればそのまま使える
- スキルの使い方は2通り:
  - **自動トリガー**: 関連するリクエストをすると、スキルの説明文に基づいて自動的に呼び出される
  - **明示的呼び出し**: `/スキル名` のスラッシュコマンドで直接呼び出す
- Anthropic 提供のサンプルスキルは `example-skills:` プレフィックス付き（例: `example-skills:frontend-design`）
- スキルを選ぶ際は、プロジェクトの技術スタックとの相性を考慮する（例: React/Tailwind 前提のスキルは Vanilla TS プロジェクトには不向き）

## メタ情報

- **ツール**: Claude Code
- **関連技術**: Claude Code, Skills, CLI
