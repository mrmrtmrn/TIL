# AI Session Notes - 2026-03-12

## Vercel とは何か・何ができるか

### 学んだこと

- Vercel はフロントエンドアプリケーションのホスティング・デプロイに特化したプラットフォーム
- Git リポジトリと連携して push するだけで自動デプロイできる
- Next.js の開発元でもあり、特に Next.js との親和性が高い
- フロントエンドだけでなく、サーバーレス関数（API Routes）でバックエンド処理も実行可能
- Edge Functions で軽量ロジックを CDN エッジで実行できる
- ただし、サーバーレス関数の実行時間に上限がある（無料〜Proプランで最大300秒）

### 詳細

**できること:**
- フロントエンドホスティング（React, Next.js, Vue, Svelte など）
- REST API / GraphQL（サーバーレス関数）
- SSR / Server Actions（Next.js）
- 軽いビジネスロジック・認証

**苦手なこと:**
- WebSocket や長時間のリアルタイム通信
- 常駐プロセス（デーモン）
- 重いバッチ処理・動画エンコード・機械学習推論
- DB は内蔵していない（Vercel Postgres/KV という連携サービスは別途ある）

**代替候補（本格的なバックエンドが必要な場合）:**
- Railway、Render、Fly.io などが向いている
