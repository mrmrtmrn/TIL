# AI Session Notes - 2026-04-09

## 関数型プログラミングの基礎理解

### 学んだこと

- 関数型プログラミングは「同じ入力に対して同じ出力を返す」性質を重視し、状態変更や副作用を抑える設計を中心に据える
- データを破壊的に更新せず、イミュータブルな値を使って処理を組み立てる
- 処理を小さな関数に分割し、関数合成で読みやすく再利用しやすいコードを作る
- 代表的な言語として Haskell / OCaml / Clojure / Scala / F# がある
- 純粋関数型の考え方は専用言語だけでなく、TypeScript / Python / Ruby などでもスタイルとして取り入れられる

### RubyとHaskellの比較で理解したポイント

- Rubyでも `map` / `select` / `sum` を使い、関数型に近い書き方は可能
- 一方でHaskellは副作用の扱いと型安全性が言語仕様として強く設計されており、関数型スタイルが標準になっている
- そのため「できる」だけでなく「自然にそう書く」文化を学びやすい

### 関数合成の具体例

「配列から偶数を抽出し、2倍して、合計する」という処理を関数の連結として表現できる。

```haskell
numbers = [1, 2, 3, 4, 5, 6]
result = sum (map (*2) (filter even numbers))
```

さらに関数合成を使うと、処理の意図を前面に出して書ける。

```haskell
result = sum . map (*2) . filter even
```

この流れは以下の3ステップに分解できる。

1. `filter even` で偶数のみ残す
2. `map (*2)` で各要素を2倍する
3. `sum` で合計する

### Haskellを学ぶメリットと用途

- 副作用の分離や型による制約を通じて、バグを早期に防ぎやすい
- 並列処理やテストでの見通しが良くなる
- 信頼性重視の領域（金融、ブロックチェーン、複雑な業務ロジック、研究・教育）で価値を発揮しやすい
