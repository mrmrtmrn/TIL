## Playwrightの基礎と特徴

### 学んだこと

- PlaywrightはWebブラウザ操作を自動化するためのツールで、主にE2Eテストで活用される
- Chromium / Firefox / WebKit を統一されたAPIで操作できる
- JavaScript（Node.js）を中心に、Python / Java / C# など複数言語に対応している
- クリックや入力などのブラウザ操作をコードとして記述して実行する

### 詳細

Playwrightでは、ブラウザを起動してページを開き、要素を指定して操作する。

```javascript
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage();

  await page.goto('https://example.com');
  await page.click('button#submit');

  await browser.close();
})();
```

## ブラウザエンジンの理解

### 学んだこと

- ブラウザとレンダリングエンジンは別の概念である
- レンダリングエンジンはHTML/CSS/JSを解釈し、画面表示を担う
- 主なエンジンは以下の通り
  - Chrome → Blink
  - Safari → WebKit
  - Firefox → Gecko
- WebKitはSafariやiOSブラウザで使われているエンジンである

## PlaywrightとSeleniumの違い

### 学んだこと

- Playwrightは比較的新しく、モダンな設計思想を持つ
- Seleniumは歴史が長く、実績と対応範囲が広い
- 主な違いは以下の通り
  - Playwright: 高速・セットアップが簡単・安定性が高い
  - Selenium: 対応言語やエコシステムが豊富
- Playwrightはブラウザドライバへの依存が少なく、シンプルに扱いやすい

## なぜPlaywrightが注目されているか

## 関数型プログラミングの基礎理解

### 学んだこと

- 関数型プログラミングは「同じ入力に対して同じ出力を返す」性質を重視し、状態変更や副作用を抑える設計を中心に据える
- データを破壊的に更新せず、イミュータブルな値を使って処理を組み立てる
- 処理を小さな関数に分割し、関数合成で読みやすく再利用しやすいコードを作る
- 代表的な言語として Haskell / OCaml / Clojure / Scala / F# がある
- 純粋関数型の考え方は専用言語だけでなく、TypeScript / Python / Ruby などでもスタイルとして取り入れられる

### RubyとHaskellの比較で理解したポイント

- Rubyでも `map` / `select` / `sum` を使い、関数型に近い書き方は可能
- 一方でHaskellは副作用の扱いと型安全性が言語仕様として強く設計されており、関数型スタイルが標準となっている
- そのため「できる」だけでなく「自然にそう書く」文化を学びやすい

### 関数合成の具体例

「配列から偶数を抽出し、2倍して、合計する」という処理を関数の連結として表現できる。

```haskell
numbers = [1, 2, 3, 4, 5, 6]
result = sum (map (*2) (filter even numbers))
```

さらに関数合成を使うと、処理の意図を前面に出して書ける。

```haskell
result = sum . map (*2) . filter even
```

この流れは以下の3ステップに分解できる。

1. `filter even` で偶数のみ残す
2. `map (*2)` で各要素を2倍する
3. `sum` で合計する

### Haskellを学ぶメリットと用途

- 副作用の分離や型による制約を通じて、バグを早期に防ぎやすい
- 並列処理やテストでの見通しが良くなる
- 信頼性重視の領域（金融、ブロックチェーン、複雑な業務ロジック、研究・教育）で価値を発揮しやすい
