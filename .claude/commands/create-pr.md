---
description: "本日の差分からPRを自動作成"
---

以下の手順でプルリクエストを作成してください：

1. 現在のブランチ名を確認し、ブランチ名から日付を抽出
   - ブランチ名は `YYYY-MM-DD` 形式（例: `2025-11-20`）
   - この日付をPRのタイトルに使用

2. `Diary/YYYY/MM/YYYY-MM-DD.md` ファイルの存在確認：
   - **ファイルが存在しない場合**：エラーメッセージを表示して処理を中止
   - エラーメッセージ: 「Diaryファイルが見つかりません。先に `/daily-summary` コマンドを実行してください。」
   - **ファイルが存在する場合**：次のステップへ進む

3. PRのbodyを作成：
   - `Diary/YYYY/MM/YYYY-MM-DD.md` ファイルからトピック（### で始まる見出し）を抽出
   - トピックを箇条書きで列挙（番号や「###」は除く）
   - 例：
     ```
     - GitHub CLIを使ったPullRequestの作り方
     - カスタムコマンドの作成方法
     ```

4. PRを作成：
   - タイトル: `TIL : YYYY-MM-DD` 形式
   - Body: 変更内容の簡潔なリスト（日本語）
   - ベースブランチ: `main`
   - ヘッドブランチ: 現在のブランチ
   - `gh pr create` コマンドを使用

**重要:**
- すべて日本語で記述
- PRのbodyは簡潔に、タイトルの列挙のみ
- 詳細な説明は不要
