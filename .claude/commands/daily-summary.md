---

以下の手順で本日の学習記録を作成してください：

1. 現在のブランチ名を確認し、ブランチ名から日付を抽出
   - ブランチ名は `YYYY-MM-DD` 形式（例: `2025-11-19`）
   - **重要**: サマリファイルの日付は、コマンド実行日ではなく、必ずブランチ名の日付を使用すること
2. mainブランチとの差分を確認：
   - `git diff main...HEAD` で変更されたファイルの内容を確認
   - `git log main..HEAD` でコミットメッセージを確認
3. 差分の内容を分析し、以下を特定：
   - 追加・変更されたファイルとその目的
   - 学んだ技術や概念
   - 実装した機能や修正したバグ
4. `Diary/YYYY/MM/YYYY-MM-DD.md` ファイルの存在を確認
   - **ファイルが既に存在する場合**：AskUserQuestion ツールを使用して、以下の選択肢をユーザーに提示：
     - 「上書きする」: 既存ファイルを完全に置き換える
     - 「追記する」: 既存の内容を保持し、新しいトピックを追加する
     - 「キャンセル」: 処理を中止する
   - **ファイルが存在しない場合**：次のステップへ進む
5. `Diary/日記テンプレート.md` のテンプレートを参考に、`Diary/YYYY/MM/YYYY-MM-DD.md` ファイルを作成または更新
   - **日付はブランチ名から抽出した日付を使用**（本日の日付ではない）
   - ファイルパスの例: ブランチが `2025-11-19` なら `Diary/2025/11/2025-11-19.md`
   - 学んだことを分かりやすくまとめる
   - コードやコマンドの例を含める
   - 参考リンクがあれば追加
   - 最後に全体のまとめを記述
   - **追記の場合**：既存の「まとめ」セクションの前に新しいトピックを追加し、まとめも更新

**重要:**
- すべて日本語で記述
- 具体的で読みやすい内容にする
- テンプレートの構造に従う
