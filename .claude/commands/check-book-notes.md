---
description: "読書メモの著作権リスクをチェック"
---

以下の手順で、docs/Books/ ディレクトリ内の読書メモファイルの著作権リスクをチェックしてください：

1. **対象ファイルの特定**：
   - `git diff --name-only` および `git diff --cached --name-only` を実行
   - 変更またはステージングされているファイルのうち、`docs/Books/` ディレクトリ配下の `.md` ファイルのみを抽出
   - 対象ファイルが見つからない場合：
     - 「Booksフォルダに変更は見当たりませんでした」と表示して終了

2. **差分の取得**：
   - 特定した各ファイルについて、`git diff` で変更内容（差分）を取得
   - ステージングされている場合は `git diff --cached` も確認

3. **著作権リスクの審査**：
   各ファイルの差分を以下の基準でチェック：

   a. **丸写しチェック**：
      - 長い段落（5行以上）がそのまま転記されていないか
      - 本の文章を思わせる、形式的・説明的な長文がないか
      - 自分の言葉で再構築されているか

   b. **引用の適正化**：
      - 引用記号（>）なしで、著者の文章をそのまま使用していないか
      - 引用する場合、出典が明記されているか

   c. **画像の確認**：
      - 書籍のページを撮影したと思われる画像リンク（![...](...)）が追加されていないか
      - 本のスクリーンショットや写真が含まれていないか

   d. **独自性**：
      - 単なる要約で終わらず、自分の感想や気づきが含まれているか
      - 「試したこと」「今後やること」など、個人的な視点が入っているか

4. **結果の出力**：

   **問題がない場合**：
   ```
   ✅ OK: 著作権リスクは見当たりません。コミット可能です。

   チェック済みファイル:
   - docs/Books/xxx.md
   - docs/Books/yyy.md
   ```

   **懸念がある場合**：
   ```
   ⚠️ 修正推奨: 以下のファイルに著作権上の懸念があります。

   📄 docs/Books/xxx.md
   - [丸写しチェック] ○○行目付近に、本文をそのまま転記している可能性があります。自分の言葉で再構築してください。
   - [引用の適正化] ○○行目の引用に出典が明記されていません。

   📄 docs/Books/yyy.md
   - [画像の確認] 書籍のページ写真と思われる画像が含まれています。削除してください。
   ```

**重要**：
- 審査は差分（変更部分）のみを対象とする
- 具体的な行や箇所を指摘する
- 修正方法を簡潔に提案する
- すべて日本語で出力する
